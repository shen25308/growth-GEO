GrowthHub public cover revision | 2026-10-12

Design read: public resource-community entrance for growth practitioners;
quiet editorial hierarchy, actual content, native green identity.
Design variance 5 / motion 3 / density 3.

References already inspected:
- Profound https://www.tryprofound.com/ : strong title hierarchy and whitespace.
- GitHub https://github.com/ : public entry distinct from sign-in and work area.
- Product Hunt https://www.producthunt.com/ : actual resource and author discovery.
These references inform hierarchy, not copied artwork or proprietary assets.

Previous concept rejected by the user:
The generated folded-book sculpture attempted to symbolize knowledge spreading.
It was an original image, not a Profound reference. Its layered silhouette read as
clutter, and the slogan copy felt formulaic. Removed both generated JPEGs from
public assets and removed their cache rules. Original historical work is in Git.

Revised design:
- Direct headline: 增长从业者的开放资源库.
- Single factual description: 发现和分享增长 Skills、实战心得与开源工具。
- Centered typography above a real published resource, fetched in existing SSR.
- Resource title, description, author, topic, update date are live data.
- Full resource and discussion links go to actual persistent resource routes.
- Topic links and View all filter the live community. No made-up counters or posts.
- Sage page, forest resource-action panel, restrained borders and one soft shadow.
- Keep the selected forest login canvas/card; align wordmark, typography,
  green accents, button geometry and explanatory copy with the cover.
- Entrance uses transform only: content is visible immediately. Hover feedback
  uses small shifts and shadow changes, no looping animation or JS dependency.
- Reduced motion disables all entrance and hover transitions.

Validation and self-review:
- Desktop 1440, mobile 390 and 320 reviewed in actual browser.
- Title > resource title > description > metadata hierarchy is clear.
- Primary entry visible in the first phone viewport; no horizontal overflow.
- Discussion route and cover-to-signup navigation verified with real resource.
- Auth keeps Google and email, no Apple; password fields remain 16px on mobile.
- Content volume is currently one published resource. Do not fill the layout with
  fabricated entries. This is a restrained first release, not parity with GitHub.
